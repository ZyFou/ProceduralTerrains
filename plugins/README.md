# Engine plugins

Procedural Terrains ships native integrations for Unity and Blender. Both
plugins can import the renderer-neutral `.ptrterrain` document and the
production ZIP exports generated by the studio.

| Engine | Version | Requirements | Source | Download |
| --- | --- | --- | --- | --- |
| Unity | `0.4.0-alpha.1` | Unity `6000.3+` | [`unity/Packages/com.zyfou.procedural-terrains`](unity/Packages/com.zyfou.procedural-terrains) | [`procedural-terrains-unity-0.4.0-alpha.1.zip`](../public/downloads/plugins/procedural-terrains-unity-0.4.0-alpha.1.zip) |
| Blender | `0.4.0` | Blender `5.2+` | [`blender/procedural_terrains`](blender/procedural_terrains) | [`procedural-terrains-blender-0.4.0.zip`](../public/downloads/plugins/procedural-terrains-blender-0.4.0.zip) |

Both 0.4 plugins add density-aware fine detail, assembly-wide thermal erosion,
procedural sand/grass/rock/snow surfaces, quality presets, and independently
toggleable placeholder water for native generation and imports. Unity retains
native TerrainData; Blender retains editable mesh assemblies. Old generation
recipes retain their original relief and preview material. No clouds or props
are generated.

See the [Unity README](unity/Packages/com.zyfou.procedural-terrains/README.md)
or [Blender README](blender/procedural_terrains/README.md) for installation and
host-application workflows. The website serves the archives from
`/downloads/plugins/`.
