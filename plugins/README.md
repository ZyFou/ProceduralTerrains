# Engine plugins

Procedural Terrains ships native integrations for Unity and Blender. Both
plugins can import the renderer-neutral `.ptrterrain` document and the
production ZIP exports generated by the studio.

| Engine | Version | Requirements | Source | Download |
| --- | --- | --- | --- | --- |
| Unity | `0.3.0-alpha.1` | Unity `6000.3+` | [`unity/Packages/com.zyfou.procedural-terrains`](unity/Packages/com.zyfou.procedural-terrains) | [`procedural-terrains-unity-0.3.0-alpha.1.zip`](../public/downloads/plugins/procedural-terrains-unity-0.3.0-alpha.1.zip) |
| Blender | `0.3.3` | Blender `5.2+` | [`blender/procedural_terrains`](blender/procedural_terrains) | [`procedural-terrains-blender-0.3.3.zip`](../public/downloads/plugins/procedural-terrains-blender-0.3.3.zip) |

Unity 0.3 adds native seeded terrain creation, tiled `TerrainData`, connected
neighbors, persistent generation recipes, and density validation. Blender 0.3
adds native Noise Stack creation, validated imports, editable mesh assemblies,
source metadata, and resize/reposition controls.

See the [Unity README](unity/Packages/com.zyfou.procedural-terrains/README.md)
or [Blender README](blender/procedural_terrains/README.md) for installation and
host-application workflows. The website serves the archives from
`/downloads/plugins/`.
